# FME 1000 Midterm Study Guide

A standalone study site for the FME 1000 midterm. It includes concept checks, written C-E-A-R case practice, a timed mock exam, and a subject-organized master study guide.

## Files

- `index.html` — the complete static practice website
- `FME1000_Midterm_Master_Study_Guide.pdf` — printable 15-page guide
- `FME1000_Midterm_Master_Study_Guide.md` — editable guide source

The site has no build step or external dependencies. Open `index.html` directly or serve the directory with any static host.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000`.

All progress and written drafts are stored in the browser's local storage.
